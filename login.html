Instagram Login Setup

One-time developer configuration

Instagram login requires a Meta Developer App. Follow these steps to enable it.
1
Create a Meta Developer App
Go to developers.facebook.com/apps → Click Create App → Choose Consumer type.
2
Add Instagram Basic Display
In your app dashboard → Add Product → Select Instagram Basic Display → Click Set Up.
3
Set Redirect URI
Under Instagram Basic Display → Basic Display, add this as Valid OAuth Redirect URI:
https://localspot-app.vercel.app/login.html
4
Copy your Instagram App ID
From Instagram Basic Display → Basic Display, copy the Instagram App ID.
5
Paste App ID in login.html
In login.html, replace YOUR_INSTAGRAM_APP_ID with your copied App ID.
6
Add backend route
Add POST /api/auth/instagram in your backend to exchange the code for a token using your App Secret.
